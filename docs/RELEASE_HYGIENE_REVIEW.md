## Cleanup performed (generated artifacts only)
Deleted: `.phpunit.result.cache`, `storage/logs/laravel.log`, all compiled
Blade views / framework cache / session files under `storage/framework/`,
and `bootstrap/cache/{packages,services}.php`.
**Regeneration proof:** immediately afterwards, `php artisan migrate:fresh
--seed` ran clean and the full suite passed (**121 tests, 529 assertions**)
— nothing in the project depends on stale local artifacts.
The local `database/database.sqlite` was re-created fresh by that seed run;
it remains in the working tree for development and stays excluded from
distribution.
